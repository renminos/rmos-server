# RMOS 用户服务器 0.12.9

## 新增/修复

- 客户端与超频工具改为 GitHub 优先下载（`renminos/rmos-client`），GitHub 不可用时自动回退到平台服务器。
- 总服务器每 30 分钟自动检查 GitHub 客户端发布，也可以在“平台管理 → 客户端版本”页手动立即同步；每个编译版本都保留，历史版本不会被覆盖。
- 普通服务器从平台同步客户端时同样优先使用 GitHub 下载地址，失败后回退平台服务器。
- 矿机详情页新增“升级客户端”按钮：先检查版本，已是最新版会提示；可升级时确认后下发，升级完成后自动重新应用超频并启动飞行表，弹窗中始终提供 SSH 手动升级指令。
- 矿场批量升级弹窗补充 SSH 手动升级指令与升级后行为说明。
- 普通服务器在线升级仍从 `rmos-server` 仓库的版本清单检查（GitHub 优先），支持 Ubuntu 直接部署与 Docker 两种方式。

## Ubuntu 直接部署

1. 将 `ubuntu/` 整个目录上传到服务器。
2. `sudo bash ubuntu/install.sh`
3. 访问 `http://<服务器IP>:18808` 完成首次初始化。

## Docker 部署

1. 将 `docker/` 整个目录上传到服务器。
2. `cd docker && cp .env.example .env`，按需修改环境变量。
3. 启动：

```bash
docker compose up -d --build
```

4. 数据保存在 `docker/data/`。

## 端口

- `18808` 网页控制台
- `19809` 矿机通信通道
- `21080-21089` VPN 等扩展端口
