# RMOS 用户服务器

RMOS 用户服务器是一套可独立部署的矿场管理系统，适合矿场主在自己的服务器、NAS、云主机或 Windows 电脑上运行，用于统一管理矿机。网页端即可完成矿机接入、飞行表、超频、插件、用户计费与备份恢复等日常运维。

**当前版本**：用户服务器 `0.16.2.0`（Linux / Docker / Windows） · Linux 矿机客户端 `0.11.15`。
下载地址：<https://github.com/renminos/rmos-server/releases> · 矿机客户端：<https://github.com/renminos/rmos-client/releases>

> 本版为**正式版**：`0.16.2.0-beta.1 ~ beta.4` 的全部改动都在此版本中，`version.json` 的 `linux-amd64` 与 `windows-amd64` 均指向本版本。Windows 版为单程序（窗口 + 服务端同一文件），解压 `rmos-server.zip` 双击即用。

## 本版更新（0.16.2.0）

- **其他矿场的全局飞行表在本矿场改为只读**：全局飞行表会被同账号的其它矿场看到并可直接使用，但它的定义属于创建它的那个矿场。现在在「借用」它的矿场里，行菜单的 **编辑 / 移除** 都是禁用状态（鼠标悬停说明去哪改），批量删除也会自动跳过它们；**复制** 仍然可用 —— 想在本矿场改，就先复制一份。
- **全局标记显示所属矿场名**：原来显示「全局 · 其他矿场」，现在显示「全局 · 矿场名」，一眼看出这张表是谁家的；其他矿场的全局标记改用虚线边框，和本矿场自己的全局表区分开。
- **修复：其他矿场的全局飞行表展开后钱包只有名字、没有地址**。钱包列表只加载了当前矿场，别的矿场的钱包查不到，于是地址与「复制地址」按钮都不显示。现在会按需拉取相关矿场的钱包用于展示（创建/编辑飞行表时仍然只能用本矿场自己的钱包，避免跨矿场引用）。
- **矿场页批量操作后自动取消多选**：执行 **批量切换飞行表 / 批量重启（Miner 与系统）/ 批量关机** 之后，勾选状态（含每矿场缓存）自动清空，工具栏不再一直显示「已选 N 台」。其它批量命令（VPN、插件、超频模板、运行指令、客户端升级、矿机迁移）**保留**选中状态，方便继续对同一批矿机操作；命令发送失败时也不清空，便于直接重试。
- **Windows 版修正：桌面窗口不停弹出 cmd / 终端黑框（重要）**。窗口每 2 秒刷新一次状态，而这条路径上有两个没有隐藏控制台的子进程（查防火墙规则的 `netsh`、取本机 IP 的 `powershell.exe`），程序本身又是无控制台的 GUI，于是每 2 秒各开一个新的控制台窗口，关掉还会继续弹。
  - 现在该程序内**所有**子进程统一走 `hiddenCommand()`（`CREATE_NO_WINDOW` + `HideWindow`）；取本机 IP 改为**进程内枚举网卡**；防火墙探测加 30 秒缓存并在切换开关后立即失效；并新增守护测试，包内再出现裸 `exec.Command(...)` 或刷新路径里再起进程就直接测试失败。
  - 实测同一台机器：修复前 9 秒内新增可见控制台窗口 **3 个**（控制台类进程 4→11）；修复后 12 秒内 **0 个**（进程数不变），内部服务器仍正常 `healthz` 返回 0.16.2.0。**版本号保持 0.16.2.0**，只替换 Windows 两个资产与清单哈希。

## 主要功能

- **Linux 矿机一条命令接入**：控制台生成接入码后按页面命令安装（脚本会自动避开 `HiveOS`/`ubuntu` 这类通用主机名，防止重装抢占别的矿机记录）。
- **Windows 用户服务器（单程序：窗口 + 托盘）**：解压即用，双击 `rmos-server.exe` 同时得到桌面窗口与用户服务器；窗口内可 启动/停止/重启、打开网页控制台、**设置开机自启动**、查看实时日志、**在线更新**；托盘菜单含 显示窗口 / 隐藏窗口 / 打开控制台 / 启动 / 停止 / 开机自启 / 退出。与 Linux 版功能完全一致，业务全部在网页控制台。
- 多矿场、多矿机管理，实时查看在线状态、算力、温度、功耗与显卡信息。同服务器矿场可在用户之间共享。
- 首页统计：矿场 / 矿机 / GPU 的 **在线 / 故障 / 离线 / 总数** 与**全账号总功率**（自动 W↔KW）。
- 飞行表：新建、编辑、导入导出（JSON / 剪贴板）、收藏与批量应用；支持**全局**飞行表（勾选后在此账号任何矿场可见可用），列表排序 收藏+全局 → 收藏 → 全局 → 未勾选，可多选批量改标记或删除；导出的 JSON 不含 RMOS 私有字段，可直接给原版生态使用。
- 飞行表切换失败时矿机不会偷偷跑回旧表：**停掉旧表矿工 → 上报原因 → 每 3 分钟重试被指派的飞行表**（Linux 客户端 0.11.4 起）。
- 超频模板：核心 / 显存 / 风扇 / 功耗限制，可对单卡或整机应用；显卡按 **PCI 地址（槽位）** 识别，拔卡/换卡不再张冠李戴，丢失的卡在原槽位标记。
- 网页 SSH、局域网 SSH；插件、VPN、个性化功能由管理员上传，所有用户的矿机可按需获取。
- 普通用户自助注册与计费，管理员可设置收费规则、暂停收费、调账与查看账务流水。
- 用户控制台：余额、充值、充值码、两步验证、充值 / 消费记录。
- 公告、审计日志与加密备份恢复；矿机侧安全扫描脚本（`release/security/`）。

## 部署要求

- **Linux / NAS**：Ubuntu 20.04 / 22.04 / 24.04（x86_64），或支持 Docker Compose 的主机 / NAS。
- **Windows**：Windows 10 / 11 x64 或 Server 2016+；需要 Microsoft Edge WebView2 运行时（Win10/11 一般已预装）。
- 可访问外网（初始化时需自动完成平台注册，连接不上平台将无法继续）。
- 放通端口：`18808`（网页控制台）、`19808`（平台通信）、`19809`（矿机通信）、`21080-21089`（客户端与工具下载，Docker/Linux 版使用）。
- 平台接入地址由系统内置，安装后自动获取并注册，**不可修改**。

## 部署方式

### Ubuntu / Linux 直接部署（推荐）

在服务器上执行一条命令：

```bash
curl -fsSL https://raw.githubusercontent.com/renminos/rmos-server/main/install.sh | sudo bash
```

安装完成后打开 `http://服务器IP:18808`，按引导完成首次初始化。

### Docker 部署

```bash
# 下载并进入 Docker 发布目录后，复制环境变量并启动
cp .env.example .env
docker compose up -d --build
```

数据保存在 `docker/data/`，容器会随主机重启自动恢复运行。

### Windows 单程序部署

1. 从 [Releases](https://github.com/renminos/rmos-server/releases) 下载 `rmos-server.zip`，解压到任意目录（例如 `D:\RMOS`）——解压后只有一个 `rmos-server\` 文件夹，里面只有 `rmos-server.exe` 和说明文件。
2. 双击 `rmos-server\rmos-server.exe`：窗口出现并自动拉起服务器。
3. 防火墙弹窗勾选**专用网络**允许（`18808` 控制台、`19809` 矿机、`19808` 平台通信）。
4. 点窗口里的「打开网页控制台」，或浏览器访问 `http://127.0.0.1:18808/`。
5. 需要开机自动运行，就打开窗口里的 **开机自启动** 开关（写在当前用户 `HKCU\...\Run`，免管理员）。

Windows 版要点：

- **一个程序同时是窗口和服务器**：同一个 `rmos-server.exe`，双击是窗口，窗口内部再以隐藏方式启动服务器进程。
- **数据在 `C:\ProgramData\RMOS\userserver`**（可用 `RMOS_WINSERVER_HOME` 覆盖）：删掉程序目录不丢数据；同机多份程序共用这一份数据，配合固定端口与单实例锁，**一台设备只运行一个 RMOS**。旧便携版把数据放在程序目录 `data\` 的，首次启动会自动迁移（原目录保留）。
- 程序是 GUI 子系统，**不会出现黑色命令行窗口**；服务器日志 `server.log`、窗口日志 `gui.log` 都在数据目录里。
- 矿机安装文件不需要随包分发：初始化完成后服务器会自动从平台同步客户端与工具到本机数据目录 `client\`。

> 也可以从 Releases 下载完整发布包，Linux 侧 `ubuntu/` 用于直接部署、`docker/` 用于 Compose 部署；Windows 侧使用 `rmos-server.zip`。

## 矿机接入

在控制台矿场页面生成接入码，然后按页面给出的一条命令在矿机上执行（Linux）。安装脚本会写入守护服务并自动注册到本服务器；接入后即可在控制台看到矿机状态、显卡、算力与温度。

## 首次初始化

第一次打开控制台会进入初始化向导：

1. **服务器注册名称**：注册后不可修改，会展示给矿机安装页面。
2. **管理员账号与密码**：本服务器唯一管理员（临时默认 `admin / rmos123456`，向导里必须改成正式密码）。
3. **公网域名 / IP 与端口**：可先跳过，之后在「平台管理 → 平台设置」中修改。
4. **运营模式**：
   - 运营模式：开放普通用户注册，所有设备按档位计费；
   - 自用模式：不开放注册，提供免费矿机额度。
5. **自动完成平台注册**：无需填写平台地址或密钥，连接成功后方可继续。

> 向导完成前，服务器会保持「等待初始化」状态：平台同步、内容同步与客户端版本轮询都不会启动。

也可以选择「从备份恢复」，上传加密备份文件并输入备份密码。若旧服务器仍在运行，请先停止旧服务器并等待至少 1 小时，再由新服务器接管。

## 计费说明

### 本服务器缴费

测试期间免费，暂定免费至10月7日。
按服务器当日在线矿机峰值计费：

- 运营模式：无免费额度，从第 1 台矿机开始计费；
- 自用模式：默认免费 10 台，超出部分计费；
- 每 10 台为一个计费档位，每档 `0.25 USD/天`；
- 公式：`费用 = ⌈(当日峰值 − 免费额度) ÷ 10⌉ × 0.25`。

「平台管理 → 计费中心」顶部可查看平台账户余额、今日应缴费用与最近同步时间。

### 向本服务器用户收费

管理员可在计费中心设置：

- 本机用户免费矿机数（默认 10 台）；
- 每档矿机数（默认 10 台）；
- 每档日费（默认 `0.30 USD/天`）。

每个用户按当日在线矿机峰值计费，前 N 台免费，超出部分按档位取整收费；余额不足时仅停止新增计费，矿机不会强制下线。

## 升级

- **Linux / Docker**：在「平台概况 → 服务器版本」点升级即可一键更新；升级期间服务短暂中断，完成后自动恢复。
- **Windows**：点升级后服务器把校验通过的新版本暂存到数据目录的 `upgrade\`，回到窗口点 **重启并更新**（若不点，下次启动程序时自动完成）：程序先把自己改名备份，再放上新版本并自动重启，窗口与服务端**同一个文件一起更新**；旧文件在下次启动时清理，失败会自动回滚。
- **矿机客户端**：控制台矿机详情页可单个升级；Linux 也可用「SSH 手动升级指令」，Windows 矿机重新下载客户端后覆盖安装。

## 常见问题

**矿机一直离线？** 检查矿机网络能否访问本服务器的 `19809` 端口，并确认「平台设置 → 客户端连接地址」填写的地址正确。

**初始化提示无法连接平台？** 请检查服务器是否能正常访问外网（尤其 GitHub），修复网络后重新初始化。

**平台接入地址可以改吗？** 不可以，地址由系统内置并自动注册，设置页仅作只读展示。

**Windows 上双击没反应 / 提示拒绝访问？** 多为安全软件（360 等）拦截，请在安全软件的信任区放行 `rmos-server.exe`；界面打不开时确认已安装 WebView2 运行时，并查看 `C:\ProgramData\RMOS\userserver\gui.log`。

**Windows 上想换端口或数据目录？** 用环境变量覆盖后再启动程序（例如 `set RMOS_SLAVE_ADDR=:8080`），数据目录用 `RMOS_WINSERVER_HOME`。

## 安全建议

- 安装后立即修改默认管理员密码。
- 不要将 `18808` 控制台端口直接暴露到公网，建议仅内网访问或通过反向代理启用 HTTPS。
- 定期导出加密备份并妥善保管备份密码。
- 生产环境使用高强度随机密码，并建议开启两步验证。
- 矿机侧建议定期运行 `release/security/` 里的安全扫描脚本，排查可疑矿工进程与后门账号。
